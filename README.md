# CPP Hierarchical Inheritance - Student System

A simple C++ project that demonstrates the concept of **Hierarchical Inheritance** using Object-Oriented Programming (OOP). The project includes a base class (`Person`) and two derived classes (`Student` and `Employee`).

---

## Features

- Object-Oriented Programming (OOP)
- Hierarchical Inheritance
- Public Inheritance
- Constructors
- Function Overriding
- Data Encapsulation
- Simple Console Output

---

## Project Structure

```
Person
├── Student
└── Employee
```

---

## Classes

### Person
- Name
- Age

### Student
- Inherits from `Person`
- Grade

### Employee
- Inherits from `Person`
- Employee ID
- Salary
